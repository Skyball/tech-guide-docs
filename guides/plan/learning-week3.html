Day 17：核心 10 题

点击问题展开参考答案，先自己想再看。

写出全部 10 题的个人答案
用自己的话，不要背诵。加入自己的 demo 经验。
3 小时
Q1: Agent 和传统 Chatbot 有什么区别？
Chatbot 只生成文本，流程固定。Agent 能自主决策并执行动作（调工具），执行路径由模型动态决定，可以多轮工具调用。
加分点：结合你的 demo 说"在我的项目里，Agent 会根据用户问题自动决定是查知识库还是查订单系统"。
Q2: LangGraph vs AgentExecutor？
AgentExecutor 是内置 while 循环，不可自定义。LangGraph 是图结构，节点和边都可控。需要 HITL、多 Agent、自定义流程控制 → LangGraph。
Q3: 怎么防 Agent 无限循环？
三层防御：recursion_limit 硬限制 + State 计数器 + 重复调用检测。三层都加，硬限制是安全网。
Q4: chunk_size 怎么选？
FAQ: 128-256, 技术文档: 512-1024, 法律: 1024-2048。加分点：说"我实测过 256/512/1024，在我的数据集上 512 命中率最高"。
Q5: 向量检索 vs 关键词检索？
向量擅长语义匹配，BM25 擅长精确匹配。生产用混合检索 + Reranker。两路合并效果 > 任何单路。
Q6: 怎么评估 RAG 效果？
RAGAS 四维度：Faithfulness（忠实）、Relevancy（切题）、Precision（检索准）、Recall（检索全）。加分点：说"我用 RAGAS 评估过，Precision 是我优化的重点"。
Q7: 提示词工程核心技巧？
Few-shot > 结构化输出 > CoT > 角色设定 > Negative Prompt。生产最重要的是版本管理和 A/B 测试，不是技巧。
Q8: 多模型调度怎么做？
按复杂度路由：简单 → mini 模型，复杂 → 大模型。加 Fallback 自动切换。加预算控制。
Q9: 流式输出怎么实现？
FastAPI + StreamingResponse + SSE。关键：Nginx 关 buffering（X-Accel-Buffering: no），否则流式变批式。
Q10: 最重要的监控指标？
自动解决率。它直接衡量 Agent 有没有在干活。下降了用 Agent 指标/RAG 指标定位环节。

Day 18：补充题

HNSW 索引怎么工作？
面试回答：分层的小世界图，底层全量数据，上层稀疏跳跃连接。搜索从顶层粗定位，逐层精确。查询 O(log N)。
30 分钟
Embedding 怎么理解？
把文本变成数字向量（如 1536 维），语义相近的文本在向量空间中距离近。用余弦相似度衡量。
30 分钟
Prompt Injection 怎么防？
输入过滤层检测注入模式 + 系统 prompt 和用户输入用分隔符隔开 + 输出审核层检查敏感信息
30 分钟
LangGraph checkpoint 怎么实现持久化？
MemorySaver（内存） / SqliteSaver / PostgresSaver。State 序列化后存入，恢复时反序列化。thread_id 区分不同会话。
30 分钟

Docker 化 Agent 服务

写 Dockerfile（多阶段构建）
阶段 1 装依赖（缓存友好），阶段 2 复制代码
45 分钟
# Dockerfile
FROM python:3.11-slim AS deps
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

FROM deps AS app
COPY . .
RUN useradd -m appuser && chown -R appuser /app
USER appuser
EXPOSE 8000
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]

services:

    ports: ["8000:8000"]
    env_file: .env

    image: redis:7-alpine
    ports: ["6379:6379"]
