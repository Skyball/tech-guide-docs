对话历史压缩

实现滑动窗口 + 摘要压缩
保留最近 3 轮 + 旧对话压缩成摘要
90 分钟
from langchain_core.messages import HumanMessage, SystemMessage

async def compress_history(messages, max_tokens=3000):
    """保留系统消息 + 最近 3 轮，中间部分压缩"""
    if count_tokens(messages) <= max_tokens:
        return messages
    system = messages[0]
    recent = messages[-6:]  # 最近 3 轮（每轮 human+ai）
    middle = messages[1:-6]
    if not middle:
        return messages
    summary = await llm.ainvoke([
        SystemMessage(content="用 100 字概括这段对话的关键信息"),
        HumanMessage(content=str(middle)),
    ])
    return [system, HumanMessage(content=f"[对话摘要] {summary.content}"), *recent]

模型路由

实现简单模型路由器
简单问题 → mini 模型，复杂问题 → 大模型
60 分钟
class ModelRouter:
    def __init__(self):
        self.simple = ChatOpenAI(model="gpt-4o-mini", temperature=0)
        self.complex = ChatOpenAI(model="gpt-4o", temperature=0)

    async def route(self, query: str):
        classifier = await self.simple.ainvoke(
            f"判断这个问题的复杂度。只输出 simple 或 complex：\n{query}"
        )
        if "simple" in classifier.content.lower():
            return self.simple
        return self.complex
